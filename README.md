# MYGAME (가제)

젤다풍 카툰 그래픽의 3인칭 오픈월드 액션 어드벤처 RPG. 웹 브라우저와 Windows(.exe)에서 실행됩니다.

## 현재 구현된 것 (1단계 프로토타입)

- **월드**: 약 640m × 640m 섬 — 중앙 초원, 언덕, 바위산, 해변, 바다
- **그래픽(중)**: 카툰(셀) 셰이딩, 캐릭터 외곽선, 실시간 그림자, 바람에 흔들리는 풀과 꽃, 나무·덤불·바위, 움직이는 구름, 물결·해안 거품이 있는 바다
- **낮/밤**: 현실 30분 = 게임 24시간. 해·달 이동, 노을, 별, 하늘·조명·안개 색 변화
- **캐릭터 동작**: 대기, 걷기, 달리기, 점프, 구르기, 앉기(앉아서 걷기), 기어가기
- 적(몬스터)은 아직 없음

## 조작법

| 키 | 동작 |
|---|---|
| W A S D | 걷기 |
| Shift (누른 채 이동) | 달리기 |
| Space | 점프 |
| Q | 구르기 |
| C | 앉기 (다시 누르면 일어서기) |
| Z | 기어가기 자세 (다시 누르면 일어서기) |
| 마우스 / 휠 | 카메라 회전 / 거리 |
| T (누르고 있기) | 시간 60배 빨리감기 (테스트용) |
| H | 도움말 숨기기 |
| Esc | 마우스 해제 |

## 실행 방법

- **웹**: GitHub Pages 링크로 접속 (저장소 Settings → Pages → Source를 "GitHub Actions"로 설정해야 함)
- **Windows**: Actions 탭 → "Build Windows exe" 최신 실행 → `MYGAME-windows` 다운로드 → 압축 해제 후 `.exe` 실행
- **직접 실행 (개발용)**: Node.js 설치 후
  ```
  npm install
  npm run dev
  ```
  브라우저에서 표시된 주소(기본 http://localhost:5173) 접속

## 코드 구조

```
src/
  main.js              게임 루프, 전체 조립
  core/                입력, 노이즈, 카툰 재질/외곽선
  world/               지형, 물, 풀, 나무·바위, 구름, 낮밤, 충돌
  player/              캐릭터 모델·애니메이션, 이동 컨트롤러, 3인칭 카메라
  ui/hud.js            시계·상태 표시
electron/main.cjs      Windows 실행 파일용 래퍼
```
